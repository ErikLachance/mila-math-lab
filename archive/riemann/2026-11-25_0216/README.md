## 3. Micro-passe A — simplification structurelle de TOUTE la condition locale

Les trois valeurs résiduelles de Psi sur un élément s* d'inertie d'image cyclotomique génératrice de F7* sont distinctes. Dans la suite, toutes les représentations sont continues au sens de D096 et strictement résiduelles r0. On étudie l'idéal a défini par le polynôme caractéristique sur I et les triples produits N1(s1)N2(s2)N3(s3)=0.

Lemme : r tue a si et seulement si elle est strictement conjuguée à une représentation triangulaire supérieure signée sur TOUT Gamma, avec diagonale sur I exactement (Psi,1,Psi^-1). Plus précisément, il existe une unique matrice C triangulaire inférieure unipotente, congruente à I, qui transporte le drapeau standard au drapeau ordonné extrait de r(s*). Les coefficients de C sont trois paramètres libres. La représentation conjuguée par (C^-1,1) est triangulaire supérieure, y compris pour les éléments de signe négatif.

Preuve : Cayley-Hamilton et différences de racines inversibles donnent trois projecteurs spectraux, chacun de rang1 (par réduction et Nakayama). Dans une base propre congruente à la base standard, r(s*)=diag(lambda1,lambda2,lambda3). N1(s*)N2(s*) est un multiple inversible de E33; N2(s*)N3(s*) multiple inversible de E11. Les triples avec s arbitraire imposent dernière ligne et première colonne de r(s); la trace impose le coefficient diagonal central. Ainsi toute inertie est triangulaire supérieure avec la diagonale prescrite. Le drapeau des deux premières sommes de droites propres est unique et intrinsèque, car un opérateur triangulaire supérieur dont les valeurs diagonales sont distinctes a son drapeau spectral ordonné standard. Pour g quelconque, g s* g^-1 est dans I avec les mêmes caractères. Si eta(g)=-1, l'automorphisme theta(gmat)=J gmat^-T J fixe précisément la matrice diagonale de s* (Psi,1,Psi^-1). Dans les deux cas la relation de conjugaison signée implique que dot r(g) préserve les deux sous-modules du drapeau. Donc r(g) est triangulaire supérieure dans la base propre. Le drapeau étant congruent au drapeau standard, sa carte de Schubert ouverte a une unique matrice inférieure unipotente C : décomposition LU de toute base adaptée congruente à l'identité, dont les pivots sont unités. Le changement de base depuis la base propre est alors triangulaire supérieur, ce qui conserve cette propriété même pour le signe négatif, car theta préserve le groupe triangulaire supérieur. Réciproquement, pour une représentation supérieure, N3 envoie tout dans F2, N2 envoie F2 dans F1 et N1 tue F1; le triple est nul. Le polynôme caractéristique est immédiat. La conjugaison signée sur I (signe+) est ordinaire; les équations sont stables.

Points importants : la seule triangularité de l'inertie était déjà connue au checkpoint 23:36; la nouveauté est le drapeau canonique et la triangularité de tout le groupe local, puis l'identification de foncteurs ci-dessous. Les racines sont distinctes dans le résidu; sans cela l'argument ne s'étend pas.

## 4. Micro-passe B — lissage formel et élimination de la saturation locale pour ce datum
Soit R_ord le quotient de R^loc représentant les lifts supérieurs avec diagonale prescrite sur I. Il existe par les équations fermées (Noethérianité); on garde les bases (framed), pas de quotient par conjugaison. Toute telle représentation diagonale se décompose en la diagonale de r0 et un cocycle dans le tore diagonal T1=ker(T(R)->T(k)) trivial sur I, donc sur Gamma/I=Zhat, avec action signée. Comme Zhat est procyclique libre, un cocycle est donné par la valeur arbitraire sur Frobenius, et tout choix de trois unités congruentes au résidu se relève sur une petite extension Artin. Il n'est PAS nécessaire que Frobenius de signe négatif soit diagonal de la forme (u,1,u^-1); les trois coordonnées sont libres.

Une fois le quotient diagonal relevé, le relèvement supérieur se ramène à un cocycle dans U, groupe unipotent supérieur de dimension3. Pour une petite extension A'->A de noyau V tué par m_A', le noyau U(A')->U(A) s'identifie à u(k)⊗V, additif, l'action induite est adjoint résiduel (la partie U résiduelle est triviale). Une section continue ensembliste existe sur les anneaux Artin finis. Le défaut de cocycle donne une obstruction H²(Gamma,u(k)⊗V); si elle est nulle, corriger par une 1-cochaîne. Par Tate local, H²(Gamma,u(k)) dual de H⁰(Gamma,u(k)^*(1)). Les poids d'inertie de u sont omega²,omega²,omega⁴; les duaux tordus ont poids omega^-1,omega^-1,omega^-3, tous non triviaux. H²=0, donc le foncteur ordinaire framed est formellement lisse sur O. Ceci traite toutes petites extensions, pas seulement les anneaux de caractéristique7. L'argument utilise les invariants sous l'inertie, donc le signe de Frobenius ne change pas la nullité. En outre H⁰(Gamma,u)=0; Euler local donne dim H¹=3, donc dim Z¹=6. La diagonale a 3 paramètres non ramifiés; dimension tangente relative 9. Par le théorème standard des anneaux locaux complets formellement lisses, R_ord ≅ O[[x1,...,x9]] (non canoniquement).

Le lemme A donne une bijection naturelle sur les anneaux Artin de la catégorie : lifts tuant a <-> lifts ordinaires framed × m_R³ (carte de drapeau). Ainsi R^loc/a ≅ R_ord[[z1,z2,z3]] ≅ O[[12 variables]]. En particulier a est premier, le quotient est intègre et sans torsion. Il reste à vérifier que delta=7 d1 d2 n'est pas nul dans ce quotient.
