## Pass B: precise conditional host compatibility test for H12

This follows P(good both)>= (1-delta_q)(1-delta_d). Thus sufficient bridge: for every x in an arbitrarily late required interval, P(H_x)>delta_q+(1-delta_q)delta_d, with suitable Y satisfying x in [Y,Y^A] and all source conditions. H12 needs existence for each x, not a single pair for all x; do not union over continuum unnecessarily. ## Pass C: abstract squarefree Gram lemma (extension of Step 2)
For arbitrary complex coefficients c_n supported on 1<=n<=Z and admissible P with q>Z^2, reciprocity gives (n/q)=epsilon_n (q/s_n), where s_n is odd squarefree part after stripping primes dividing m0; epsilon_n is fixed sign because q lies in a fixed class modulo m0 divisible by 8. Let a_s=sum_{n:s_n=s} epsilon_n c_n, and use s xor t = st/gcd(s,t)^2. Then E_q |sum c_n(n/q)|^2 = sum_{s,t} a_s conjugate(a_t) r_(s xor t), with r_u=E_q(q/u). Here s xor t<=Z^2, coprime to m0. Under source Step 1 at most one exceptional e>1, |r_u|<=eta=Y^-B elsewhere except r_1=1. Therefore E|sum|^2 <= sum |a_s|^2 + |r_e| sum_s |a_s a_(s xor e)| + eta (sum |a_s|)^2 <= (1+|r_e|)sum |a_s|^2 + eta ||a||_1^2, extending a by zero. If no exceptional use r_e=0. The exceptional operator is a matching/involution, not a dense error matrix. Exact Gram form and bound valid for any coefficients, unlike source's prime-power specialization. It does not guarantee a useful bound when many coefficients accumulate in the same squarefree class; in particular neutral class and squareful terms must not be ignored. This identifies precisely the combinatorial obstruction for more elaborate test weights and can support uniform estimates once weighted squarefree class norms are controlled. No new zero-density theorem claimed.
