## Micro-pass I: complex-valued generalized Bernoulli integrality — theorem plus exact tests

For ANY Dirichlet character chi modulo N (values roots of unity or zero), any integer k>=1, let `P_k=product of primes <= k+1`. Proved elementary **arithmetic integrality theorem**: `N*P_k*B_(k,chi)` is an algebraic integer. Starting from `B_(k,chi)=N^(k-1)sum_(a=1)^N chi(a) B_k(a/N)` and expanding the Bernoulli polynomial gives `N B_(k,chi) = sum chi(a) sum_(j=0)^k binom(k,j) B_j a^(k-j) N^j`. von Staudt–Clausen and B1=-1/2 imply every denominator of B_j divides P_k, so every coefficient after multiplication is an integer, and chi(a) are algebraic integers. This is a **standalone proved elementary sublemma**, not the difficult upper bound on Selmer group length `PsiBound` from Rubinstein III.9. Exact cyclotomic polynomial arithmetic for 144 non-real primitive-character/k pairs, p=5,7,11,13,17,19, orders 1,2,3, k<=8; checked integral coefficients modulo cyclotomic polynomial and 72 parity zero instances; ALL PASS.
